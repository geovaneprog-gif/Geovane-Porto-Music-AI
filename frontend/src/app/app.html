TECNOLOGIA ENCONTRA PRODUÇÃO MUSICAL

Um laboratório de
novas interpretações.

Projeto experimental de Geovane Porto que conecta um frontend Angular a uma API Python e ao motor MuLaCover para criar versões musicais a partir de referências.

01 / Direção

Envie áudio, letra e estilo. Ajuste os parâmetros para comparar diferentes resultados.

02 / Geração

A API local processa a referência e informa as etapas disponíveis ao frontend.

03 / Escuta

Compare o áudio gerado e consulte os arquivos MIDI da transcrição.

A IA pode alterar melodia, instrumentos e métrica vocal. O resultado é experimental. A biblioteca mantém apenas as produções desta sessão; recarregar a página limpa a lista. Os áudios dependem do backend local em execução.
